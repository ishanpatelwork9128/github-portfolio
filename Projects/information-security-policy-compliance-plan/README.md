# Information Security Policy and Compliance Plan

## Project Overview

This project focused on developing an information security policy and compliance plan for a fictionalized cancer research organization. The organization was anonymized to protect sensitive and identifying information.

The project addressed cybersecurity governance, risk management, regulatory compliance, employee responsibilities, data protection, access control, incident response, and security awareness.

## Project Objectives

* Identify the organization’s primary cybersecurity risks.
* Develop practical information security policies.
* Align security practices with recognised standards and regulations.
* Establish employee responsibilities for protecting sensitive information.
* Recommend controls that support confidentiality, integrity, and availability.
* Create a structured compliance plan for continuous improvement.

## Standards and Regulations

The project considered guidance from:

* NIST Cybersecurity Framework 2.0
* HIPAA Security Rule
* NIST Special Publication 800-53
* General cybersecurity governance and risk-management practices

## Key Deliverables
